# EducaOne — dependencias DIRECTAS del backend.
#
# INFRA-1: versiones FIJAS (==), no rangos abiertos (>=).
#
# Con `>=` cada build de Render podía traer una versión distinta sin que
# cambiara una sola línea de código: el mismo commit dejaba de ser el mismo
# despliegue. Estos números NO son una actualización ni un downgrade: son
# exactamente los que Render instaló en el último build correcto
# (2026-09-09), leídos del log de ese deploy.
#
# Solo se fijan las dependencias DIRECTAS. Las transitivas se dejan resolver
# a pip a propósito: un `pip freeze` de una máquina Windows/Python 3.13 no
# describe el entorno real (Linux/Python 3.14.3) y fijarlas a ciegas podría
# romper el build. Un lock completo con hashes es trabajo de una fase aparte,
# hecha en un entorno idéntico al de producción.
#
# NOTA: el repo no fija la versión de Python. Render usa su default —hoy
# 3.14.3, según el log del build— y ese default puede cambiar solo. Fijarlo
# requiere autorización aparte: no se toca aquí.
#
# Para cambiar una versión: verificar antes que el deploy con ella fue
# correcto, y actualizar este archivo en el mismo commit.
